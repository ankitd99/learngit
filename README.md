# LearnGit

This repository is created to learn and practice basic Git and GitHub commands.

## Purpose

The purpose of this repository is to understand:

- Git repository creation
- Creating and managing files
- Git branches
- Staging files
- Creating commits
- Checking Git status
- Working with the main branch
- Pushing code to GitHub

## Git Commands Practiced

```bash
git init
git status
git branch
git add
git commit
git log
git push
git pull
